# Oasis

Malá survival webová hra zasazená do pouště. Hráč buduje bezpečné zázemí u oázy a vyráží na časově i zásobami omezené expedice pro suroviny.

## Herní smyčka

1. Připravit se u oázy: doplnit vodu, jídlo a vybavení.
2. Naplánovat výpravu podle dostupných zásob a očekávaného rizika.
3. Vyrazit do pouště, hledat suroviny a rozhodovat, kdy se vrátit.
4. Přinést kořist, vylepšit zázemí a zpřístupnit vzdálenější oblasti.

Hlavní napětí vzniká z rozhodnutí **kolik zásob investovat, jak daleko dojít a kdy se otočit zpět**.
