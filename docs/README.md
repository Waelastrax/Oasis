# Rozcestník projektu

Dokumentace je rozdělená tak, aby pro jeden úkol nebylo nutné načítat celý projektový kontext.

| Potřebuji řešit | Otevřít |
| --- | --- |
| Herní smyčku, mechaniky, rozsah nebo balanc | [`GAME_DESIGN.md`](GAME_DESIGN.md) |
| Technologie, adresáře, datové modely nebo technická rozhodnutí | [`ARCHITECTURE.md`](ARCHITECTURE.md) |

## Pravidlo pro nové dokumenty

Nový dokument vytvoř jen tehdy, když se téma nevejde do existujícího souboru bez zhoršení přehlednosti. Každý nový dokument přidej do tabulky výše a na jeho začátek napiš, co je jeho účelem.

## Zdroj pravdy

- Technická rozhodnutí: `ARCHITECTURE.md`
- Pořadí práce: `ROADMAP.md`
